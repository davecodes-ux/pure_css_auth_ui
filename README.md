# Responsive Form Landing Page
A clean, modern, and user-friendly form interface built from scratch using core web technologies. 
Designed with a focus on usability, clean layout structure, and responsive design principles.
## Built With
* **HTML5:** Semantic document structure and form elements.
* **CSS3:** Custom styling, layout design, and responsive media queries.
* **JavaScript:** Interactive behavior and input validation handling.
##  Features
* **Responsive Layout:** Adapts smoothly across mobile, tablet, and desktop screens.
* **User-Friendly Form Design:** Clean input fields with clear visual cues and modern aesthetics.
* **Input Validation:** Built-in checks to ensure data is correctly formatted before submission.
